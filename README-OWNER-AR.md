# LIWAN Restaurant — معاينة كلمة المرور من ملف PASS.Text

تم بناء هذه النسخة على منيو LIWAN الأصلي، مع إبقاء صفحة الزبون `index.html` من دون أزرار الإدارة.

## الملفات

- `PASS.Text`: **كلمة المرور التجريبية الحالية: 2027**. يمكنك تعديلها باستخدام محرر نصوص. اترك الرقم في سطر واحد دون مسافات إضافية.
- `owner.html`: شاشة إدخال كلمة المرور قبل إظهار لوحة صاحب المطعم.
- `pass-gate.js`: يتحقق عبر المتصفح من محتوى `PASS.Text`، ثم يظهر لوحة إدارة الأسعار.
- `index.html`: منيو الزبون العادي.

## التشغيل

- شغّل المشروع عبر VS Code Live Server أو عبر `python -m http.server 8000`.
- افتح `http://localhost:8000/owner.html`.
- أدخل **2027**، ثم جرّب تعديل السعر.
- افتح `index.html` على **المتصفح نفسه** لمشاهدة السعر في المنيو.
- عند تغيير الملف `PASS.Text` وإعادة تحميل صفحة صاحب المطعم، تصبح الكلمة الجديدة هي المطلوبة.
- اضغط «خروج» لإغلاق اللوحة والعودة لشاشة إدخال كلمة المرور.

## تنبيه أمني حاسم — ليس للاستخدام الفعلي

**هذا فحص واجهة تجريبي وليس نظام تسجيل دخول آمن**. GitHub Pages يعرض جميع الملفات للعامة، بما فيها `PASS.Text`؛ يستطيع أي شخص فتح الرابط المباشر للملف وقراءة كلمة المرور 2027. كما يمكن تجاوز التحقق عبر أدوات المتصفح. إخفاء الرابط أو تغيير اسم الملف لا يحل المشكلة.

أي تعديل للسعر في هذه النسخة يُخزَّن في **localStorage لدى المتصفح نفسه فقط**، ولا ينتقل إلى أجهزة زبائن آخرين، ولا توجد قاعدة بيانات مشتركة. **لا تعتمد هذه النسخة للمطعم على الإنترنت.**
