# LIWAN · Signature Edition

هذه نسخة مطوّرة من مشروع LIWAN Emerald الذي تم رفعه.

## التحسينات
- لمسات فخمة إضافية للواجهة الزمردية والذهبية والكريمية.
- حركة ظهور خفيفة للبطاقات عند التمرير، وتأثير لطيف عند إضافة منتج للسلة.
- فتح سلة المشتريات بحركة ناعمة وتعتيم خلفيتها.
- شريط تقدّم صغير أثناء تصفّح المنيو.
- ظهور تدريجي لصور المنتجات بعد تحميلها.
- تحسين حالات التركيز واللمس مع احترام إعداد تقليل الحركة.
- تعديل عبارات الترحيب فقط وإضافة خاتمة بسيطة للمنيو.

## ما لم يتغير
- `menu-data.js` كما هو بالكامل: كل الأصناف والأسعار ومسارات الصور.
- جميع الصور وأسماؤها كما وردت في الملف المرفوع.
- رقم واتساب وآلية الطلب كما هي.

## التشغيل
افتح `index.html` داخل المجلد مع الاحتفاظ بمجلد `images` بجانبه.
