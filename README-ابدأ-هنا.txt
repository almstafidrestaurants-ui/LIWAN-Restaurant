LIWAN — استعادة الدخول بكلمة مرور من PASS.Text

هذه النسخة تعيد الدخول إلى owner.html بالطريقة الأصلية:
1. حقل واحد فقط: كلمة المرور، بدون بريد إلكتروني.
2. تتم مقارنة ما يكتبه صاحب المطعم بمحتوى PASS.Text.
3. بعد نجاح المطابقة تظهر لوحة تعديل الأسعار.
4. المنيو للزبائن يبقى كما هو، مع تصحيح سعر «لحم شقف غنم مشوي» إلى 22 دولاراً في menu-data.js.

هام جداً: يتم حفظ التعديلات التي يجريها صاحب المطعم داخل localStorage على المتصفح نفسه، وليس لجميع الزبائن. كلمة المرور في PASS.Text علنية لمن يستطيع الوصول إلى ملفات GitHub Pages؛ لذلك فهي ليست مصادقة آمنة. هذا حل لاستعادة طريقة الدخول السابقة فقط، وليس حلاً للمزامنة والحماية.

لتفعيل حفظ الأسعار لجميع الزبائن مع بقاء شاشة كلمة مرور واحدة، يلزم خادم يتحقق من كلمة المرور خارج ملفات GitHub العامة ويفرض صلاحيات الكتابة، أو إعداد Firebase Authentication مع حساب ثابت مخفي من الشاشة؛ وفي هذه الحالة لا يجوز الاعتماد على PASS.Text العام ككلمة سر آمنة.

ارفع محتويات هذا المجلد إلى جذر المستودع، واستبدل الملفات التي لها الأسماء نفسها. لا ترفع مجلد المشروع بالكامل كمجلد فرعي.
