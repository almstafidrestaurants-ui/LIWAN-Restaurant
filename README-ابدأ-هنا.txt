LIWAN Firebase: الدخول بكلمة مرور فقط + مزامنة الأسعار

1- افتح README-FIREBASE-AR.md واتبع خطوات إعداد Firebase.
2- أدخل إعدادات حسابك في firebase-config.js.
3- ضع UID صاحب المطعم في firestore.rules وانشر القواعد.
4- ارفع ملفات المشروع كلها إلى GitHub، ثم احذف PASS.Text وpass-gate.js القديمين.

ملف PASS.Text لم يعد مستخدماً. لا تحفظ كلمة مرور Firebase داخل GitHub.
